# GreyScienx plugin

Portable Agent Plugins 1.0 representation of the public GreyScienx MCP service.

- Public endpoint: `https://greyscienx.com/mcp`
- Authentication: none
- Behaviour: read-only retrieval and validation against a bounded public research corpus
- Public policies: `https://greyscienx.com/privacy`, `https://greyscienx.com/terms`, `https://greyscienx.com/support`

The OpenAI public-directory submission uses the **With MCP** route and submits the endpoint directly. The packaged archive is retained as the reproducible portable plugin twin.
