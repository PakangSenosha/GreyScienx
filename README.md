# GreyScienx

GreyScienx is an independent research publication across fields of study. The public archive groups complete manuscripts into connected research series.

## Public structure

- Publication: `greyscienx.com`
- Research archive: `greyscienx.com/research`
- Founder: `greyscienx.com/about/pakang-senosha`

The research archive is text-led. Each paper opens as a complete PDF; the trading audit and Wits staff-education study are not part of the public collection.

## Research series

1. Household Economics
2. Population Futures
3. The R350 Counterfactual
4. Strategic Industrialisation
5. African Convergence

## Local development

```bash
npm install
npm run dev
```

Cloudflare-compatible development and deployment use vinext:

```bash
npm run dev:vinext
npm run build:vinext
npm run deploy:vinext
```

The site is configured for Cloudflare Workers and Workers Static Assets. Public submissions and multi-researcher collaboration remain disabled.
