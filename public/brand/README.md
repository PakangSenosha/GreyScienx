# GreyScienx wordmark

`greyscienx-wordmark.svg` is the canonical website wordmark. It reproduces the original live-text treatment: uppercase heavy sans serif, `GREY` in ink (`#131200`), `SCIENX` in coral (`#f26157`), and tracking equal to `-0.08em`.

The fixed `480 × 60` view box and explicit `textLength` values keep the proportions stable while retaining editable text. Website headers render this asset through `components/Brand.tsx`; division labels remain live HTML text for accessibility and page-specific naming.
