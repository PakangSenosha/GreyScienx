# GreyScienx X campaign task

Start each publication campaign as a separate Codex task in the GreyScienx project. Replace the bracketed values and send this as the task's first message:

> Use `$greyscienx-x-editorial` to create the complete X campaign for **[paper title]**. The canonical paper entry is in `lib/catalog.ts`. Read the full manuscript in `research/publications/[pdf filename]` and inspect relevant evidence in `research/source/`. Write all outputs to `social/x/[paper slug]/`, validate the pack, and stop before publishing or scheduling anything.

The task inherits the repository guidance in `AGENTS.md`, so the first message should remain short. One task owns one campaign directory.
